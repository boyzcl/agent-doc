# Minimal Project

这是一个匿名化的最小示例，用来演示 `agent-doc` 如何把当前规则、历史背景和证据目录分开。

## Start Here

- Agent 入口：`AGENTS.md`
- 文档总索引：`docs/index.md`
- authority 边界：`docs/authority-map.md`

## Current Focus

当前发布规则以 `docs/conventions/release-policy.md` 为准。

## Notes

- `docs/history/` 用来解释演化，不承接当前规则
- `docs/reference/` 用来存放证据目录，不默认成为规则入口
