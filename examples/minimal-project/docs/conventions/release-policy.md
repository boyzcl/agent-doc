# Release Policy

## Goal

这份文档定义当前有效的发布规则。

## Rules

1. 发布前必须完成 smoke 检查。
2. 发布规则的当前口径只维护在本文件。
3. 历史方案和证据目录只允许通过链接引用，不允许复制为第二套正式规则。

## Exceptions

- 紧急情况可以跳过非关键检查，但必须在事后补记录。
